Every project keeps its own `CONTRIBUTING` guidance in its repository. In
general:

1. Open an issue before a large change, so the approach can be agreed first.
2. Branch from `main`, one concern per branch.
3. Open a pull request — every PR gets a real review, and reviews are meant to
   teach, not just gatekeep.
4. If AI helped, say how in the pull request description — see
   [AI assistance in contributions](/ai/contributing/).

## Where to start

New contributors are usually best served by issues labelled `good first issue`
in the project repositories under
[github.com/codrlabs](https://github.com/codrlabs).
